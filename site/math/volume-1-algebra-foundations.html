Concept guide

Linear Equations in One Variable

Build and solve equations by undoing operations in reverse order.

  • Keep both sides balanced.
  • Clear fractions early when helpful.
  • Translate words into an equation before calculating.
ax + b = ca(x + b) = cax + b = dx + e
Common mistake: Do not distribute or move terms without changing every affected sign.
Concept guide

Linear Functions and Rate of Change

Connect equations, tables, and contexts to slope and initial value.

  • Slope is change in y divided by change in x.
  • The y-intercept is the value when x = 0.
  • In context, include units when interpreting slope.
y = mx + bm = (y₂ − y₁)/(x₂ − x₁)
Common mistake: Do not confuse the starting value with the rate of change.
Concept guide

Linear Equations in Two Variables

Represent lines using standard form, slope-intercept form, points, and intercepts.

  • Substitute an ordered pair to test it.
  • Set y = 0 for the x-intercept.
  • Set x = 0 for the y-intercept.
Ax + By = Cy = mx + b
Common mistake: When solving for y, divide every term by the coefficient of y.
Concept guide

Systems of Linear Equations

Find where two linear relationships are true at the same time.

  • Substitution is efficient when a variable is isolated.
  • Elimination is efficient when coefficients match.
  • Parallel lines have no solution; the same line has infinitely many.
a₁x + b₁y = c₁a₂x + b₂y = c₂
Common mistake: After solving one variable, substitute back to find the other.
Concept guide

Linear Inequalities

Model ranges, limits, minimums, and maximums.

  • Reverse the inequality when multiplying or dividing by a negative.
  • “At most” means ≤; “at least” means ≥.
  • Check whole-number constraints in word problems.
ax + b < cL < ax + b < U
Common mistake: An equality endpoint is included only with ≤ or ≥.
